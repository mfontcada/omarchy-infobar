# omarchy-infobar

> **AI disclaimer:** Most of the code and documentation in this project was generated by AI coding agents powered by large language models (LLMs).

`omarchy-infobar` is an always-visible companion bar for Omarchy. It runs inside the
existing `omarchy-shell` process and adds a second bottom bar without
replacing or modifying Omarchy's normal top bar.

The first module displays CPU, GPU, RAM, disk, and temperature information.
The project is intentionally modular so additional information and controls
can be added later.

## Compatibility

`omarchy-infobar` is an Omarchy plugin, not a standalone Quickshell bar. It
requires an Omarchy installation with `omarchy-shell` and Quickshell support.
It is designed for Linux systems with procfs and sysfs, Bash, `awk`, and
`df`.

Hardware-specific values depend on the available tools and drivers:

| Information | Source | Fallback behavior |
| --- | --- | --- |
| CPU usage | `/proc/stat` | `--` if sampling fails |
| CPU temperature | `sensors`, thermal zones | `--` if unavailable |
| NVIDIA GPU | `nvidia-smi` | usage and temperature become `--` |
| AMD GPU | DRM/sysfs | unsupported values become `--` |
| Intel GPU | DRM/sysfs, optional `intel_gpu_top` | unsupported values become `--` |
| Memory | `/proc/meminfo` | unavailable values may show `--` |
| Disk | `df` for `/` | reports the root filesystem |

The plugin does not use the network, require elevated privileges, or read
credentials. Plugins run as unsandboxed code inside `omarchy-shell`, so review
the source before enabling third-party copies.

## Development installation

From this repository, install the plugin directory with:

```bash
mkdir -p ~/.config/omarchy/plugins/omarchy-infobar
cp manifest.json Infobar.qml SystemInfo.qml README.md ~/.config/omarchy/plugins/omarchy-infobar/
cp -r scripts ~/.config/omarchy/plugins/omarchy-infobar/
chmod +x ~/.config/omarchy/plugins/omarchy-infobar/scripts/sysinfo.sh
omarchy-shell shell rescanPlugins
omarchy plugin enable omarchy-infobar
```

The plugin watches its files and normally hot-reloads after changes.

## Local testing

Run validation without changing your Omarchy configuration:

```bash
bash scripts/test-local.sh
```

To test the live panel, link this working tree into the Omarchy plugin
directory and enable it:

```bash
bash scripts/test-local.sh --install
```

The install mode refuses to replace an existing non-local plugin directory.
When finished, remove the test link with:

```bash
bash scripts/test-local.sh --remove
```

## Publishing

Publish this directory as its own Git repository. Add a screenshot captured
from a running installation to the repository before the first release. Users
can then install it
with:

```bash
omarchy plugin add <repository-url> --enable --yes
```
